# Hack-n-Hook_Controller

## Einführung

Das Ziel ist es, eine Angel zu bauen, welche ein Spiel steuert.
Dieses Repo behandet nur die Angel. Das Spiel hat sein Eigenes Repo

## Bestandteile

Die Angel hat einen 3D-Gedruckten Körper. 
Ganz unten sitzt ein Heltec WIFI Kit 32 v3 welches mit einem Rotary Encoder (welcher als Kurbel agiert) und einer MPU6050 (Accelerometer + Gyro zum Messen ob die Angel ausgeworfen ist) verbunden ist.

## Struktur

Im Folder `3D_Modelle_Rute` sind alle 3D Modelle beinhaltet und in `ESP32_Code` ist der Code des ESPs.
